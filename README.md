# «ГДЕ АРТИКЛЬ?!»

Абсурдная браузерная игра про обычный урок восточноармянского, который вышел из-под контроля. 5–10 минут, шесть эпизодов, финальный экзамен и диплом «Министерства потерянных артиклей».

**Всё, что нужно для запуска, — один файл gde-artikl.html.** Ни сервера, ни интернета, ни установки.

---

## 1. Как открыть

1. Скачайте gde-artikl.html.
2. Откройте его в браузере (двойной щелчок / «Открыть с помощью» → Chrome, Edge, Firefox, Safari).
3. Нажмите **«НАЧАТЬ УРОК»**.

Игра полностью автономна: HTML, CSS, JavaScript, графика и звук внутри файла. Внешних запросов нет — после скачивания интернет можно отключить.

## 2. Telegram и мобильные браузеры (честно)

Отправляйте друзьям **как документ/файл**, а не как медиа.

- **Компьютер:** скачанный файл открывается двойным щелчком в обычном браузере. Это основной, гарантированно рабочий сценарий.
- **Telegram-просмотрщик внутри приложения:** локальный HTML там обычно не запускается (особенно на телефонах). Это нормально — файл нужно именно скачать.
- **Android:** скачайте файл и откройте его в Chrome («Открыть с помощью» → Chrome). Некоторые файловые менеджеры по умолчанию показывают HTML как текст — тогда выберите браузер.
- **iPhone / iPad:** Telegram не даёт открыть локальный HTML напрямую. Сохраните файл в «Файлы» (Поделиться → «Сохранить в Файлы»), затем откройте его из приложения «Файлы». Если Safari отказывается запускать локальный HTML из «Файлов» — это ограничение iOS; можно использовать файловый менеджер со встроенным браузером. На реальном iPhone игра **не тестировалась** (см. §7).
- **Офлайн:** после скачивания интернет не нужен. Исключение — первый запуск аудио требует касания/клика (обычное правило браузеров, а не сети).

## 3. Управление

- Мышь или палец. Все игровые элементы крупные, hover не обязателен, клавиатура не обязательна.
- Во время катсцен **тап/клик по экрану ускоряет** (или пробел/Enter).
- Кнопка **🔊/🔇** справа сверху: звук включается после первого касания, состояние запоминается.
- На экране диплома: **«СКОПИРОВАТЬ РЕЗУЛЬТАТ»** (при недоступном Clipboard API открывается выделенное поле для ручного копирования), **«СЫГРАТЬ ЕЩЁ РАЗ»**, ссылка «показать текст вручную».
- Пара пасхалок: потрогайте живой артикль на титульном экране 5 раз; пощёлкайте печать на дипломе 3 раза.

## 4. Что внутри (осторожно, спойлеры)

- **Шесть эпизодов с разными механиками:** ловля и крепление живых артиклей; побег из собственной памяти; акустический кошмар с убегающей кнопкой «Я ПОНЯЛ»; поиск настоящих армянских букв среди похожих; временная петля «мы это уже проходили»; финальный экзамен с педагогическим хаосом.
- **Сквозной сюжет:** сбежавший артикль, полицейский протокол № 47, профсоюз букв, урок, который продлевают на 40 минут. В финале — неожиданный поворот с артиклем и домашнее задание на 47 пунктов.
- **Комедия событий, а не текста:** ошибки запускают катастрофы, кнопки убегают, интерфейс ломается, учительница задаёт вопросы операционной системе. Никаких объяснений грамматики и «упражнений».
- **Настоящий армянский A1–A2:** տուն/տունը, գիրք/գիրքը, ջուր/ջուրը, հաց/հացը, կատու/կատուն, տղա/տղան, մարդ, խանութ, դպրոց, փողոց, քաղաք; фразы вроде «Ես այսօր տանը հաց եմ ուտում». Намеренные ошибки персонажей помечены в сценарии и являются частью шутки.
- **Финал:** безымянный диплом вымышленного «Министерства потерянных артиклей», 9 званий, зависящих от событий прохождения, статистика, достижения, текст для шаринга в чат.
- **Звук:** синтезированные WebAudio-эффекты (без внешних сэмплов и музыки), mute.

## 5. Технологии

- Vanilla JavaScript (classic scripts, без модулей и фреймворков), Canvas 2D для персонажей и фона, DOM/CSS для интерфейса, WebAudio для звука.
- Один HTML-файл, без CDN, внешних шрифтов, изображений, API и сети. Армянские глифы рендерятся системным шрифтовым стеком с fallback.
- Размер финальной сборки — около **490 КБ** (в пределах 1 МБ).
- Отладочные параметры: ?debug=1 (кнопка пропуска), ?auto=1 (быстрое автопрохождение), ?scene=article&only=1 (запуск одной сцены), ?diploma=1 (сразу диплом). Служебный API: window.__GAME__.

## 6. Сборка из исходников

Исходники лежат в src/, сборка — tools/build.mjs:

~~~bash
node tools/build.mjs        # собирает gde-artikl.html и dev.html
node tools/shot.mjs gde-artikl.html out.png 1280 800 1200
~~~

- src/shell.html — каркас; src/css/base.css + theme.css; src/js/*.js — движок, арт, звук, контент, сцены.
- dev.html подключает исходники внешними файлами для отладки; финальный gde-artikl.html — единый файл.
- Для тестов используется локальный Chrome/Edge через playwright-core: node tools/playtest.mjs (если присутствует).

## 7. Что проверено (и что нет)

Проверено на десктопном Chrome (headless, через Playwright) и в мобильных viewport:

- запуск через file:// без сервера; офлайн (ни одного сетевого запроса, внешних URL в файле нет);
- запуск из пустой папки вне проекта (нет относительных зависимостей);
- полное автопрохождение всей последовательности сцен до финала;
- ручное прохождение финала: домашнее задание → возвращение артикля → диплом;
- диплом: звание/статистика, достижения, копирование (Clipboard API и fallback-поле), «Сыграть ещё раз» со сбросом состояния;
- mute, сохранение состояния звука, отсутствие ошибок WebAudio;
- viewport 1280x800, 390x844 и 320x568 (портрет), тач-эмуляция;
- синтаксис всех JS-модулей, отсутствие внешних ресурсов, UTF-8 и армянские глифы;
- полный автоматизированный QA-прогон: **124 PASS / 0 FAIL** (14 сцен × 3 viewport, auto-run, диплом, тач, mute, офлайн, monkey-тап), 92 скриншота-доказательства; подробности — docs/QA.md.

Финальная сборка: 490.7 КБ, SHA-256 `FFC2C52D8E31C6BE7B488EA158DA91ADCD5D9858DE01CF2D45B4D9D9114CDE9D`.

**Не проверено:** реальные физические Android/iPhone-устройства, Safari/iOS и встроенные просмотрщики Telegram, очень старые браузеры, экзотические файловые менеджеры. Звук не проверялся «на слух» — только отсутствие ошибок синтеза.

## 8. Известные ограничения

- iOS/Telegram могут не открывать локальный HTML напрямую — это ограничение платформы, а не игры; на десктопе и в мобильных Chrome/Android путь простой.
- Если в системе нет шрифта с армянскими глифами (редко), буквы могут выглядеть иначе; используется широкий fallback-стек.
- Игра не сохраняет прогресс между перезапусками (сознательно: короткое прохождение).
- Диплом — вымышленный документ вымышленного министерства, не официальный документ.
