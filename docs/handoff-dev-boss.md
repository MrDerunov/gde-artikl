## Эп5 — G.scenes.loop (src/js/15-ep-loop.js)

### Механика (петля, не викторина)
- Сцена: HUD «ЗАНЯТИЙ: 47», карточка вопроса «Как будет «дом»?», карточки **տուն / գիրք / հաց**
  (верно տուն; подписи дом/книга/хлеб), арена для призрака, большая кнопка «Я ТОЧНО ЗАПОМНИЛ».
- Ответ (любой; ошибка — комедийный комментарий + `errors`) → появляется большая кнопка.
  Фраза-подколка: «нажми, чтобы точно забыть».
- **Нажатие большой кнопки** = `c.bump('loops')`, гаг `loop_bigbutton`, анимация очистки памяти
  (скан-линии, список стёртого: шнурки, имя кота, «այո» → ОШИБКА 404), счётчик крутится
  **47 → 247 → 447 → 647**, тот же вопрос возвращается (текст вопроса деградирует).
- **Призрак артикля** в каждом витке: canvas через `G.art.drawArticle(..., {ghost:true})`,
  плавает, живёт ~3.2 с, респавнится, если упустили. Тап = `articlesSaved+1`, гаг, штамп
  «ПРИЗРАК N/3». **3 призрака ломают петлю** (по одному за виток).
- **Деградация UI по виткам** (уровни 1–4): «Занятие № 247. Это не ошибка.», список стёртого,
  `c.fx.fakeWindow` «ПАМЯТЬ ОЧИЩЕНА / Восстановить?», «Операционная система, где артикль?» →
  «НЕ НАЙДЕНО. УСТАНОВИТЬ? КНОПКА «ДА» УБЕЖАЛА», 47 копий вопроса, убегающая большая кнопка
  на pointerover, глитчи, «404 УРОК НЕ НАЙДЕН. УРОК НАЙДЕН.»
- Пустых тупиков нет: если 13 с ничего не нажимать — «Петля нажала сама.» и виток продолжается;
  карточки при 20 с простоя отвечают за игрока.
- **Финал**: глитч, кнопка треснула, штамп «ПЕТЛЯ РАЗОМКНУТА», «Стоп.», «Мы это уже проходили.
  Но не так.», счётчик «ЗАНЯТИЙ: 1», финальный призрак, «Отлично. Продолжим.», системный анонс
  финального экзамена (мостик к i6), resolve.
- **Статистика**: loops (нажатия большой кнопки), articlesSaved (призраки), errors, gags
  (`loop_ghost_1..3, loop_bigbutton, loop_resolved, loop_auto`).
- **Достижение**: `loop_veteran` — при 5 нажатиях большой кнопки.
- **c.auto**: завершение ~1.2 с, начислено loops=3, articlesSaved=1, gag loop_auto.
- Длительность: ~36–50 с у активного игрока; больше — если злоупотреблять кнопкой.
- Мобильный портрет 390×844 и десктоп 1280×800 проверены; после пропадания `.scene-root`
  stage остаётся — штатно для single-scene прогона.

### Проверено
- `node --check src/js/15-ep-loop.js` OK; `node tools/build.mjs` OK.
- Playwright 390×844 (hasTouch): полный проход (3 призрака, 2 нажатия кнопки, 2 очистки памяти,
  fakeWindow, разрыв петли, финал) → scene-root удалён, stats: loops=2, articlesSaved=3,
  errors=0, gags=5, console/pageerror — нет. 1280×800 — то же, все 3 уровня деградации
  (247/447/647) и финальные реплики проверены.
- `?scene=loop&only=1&auto=1` — 1.2 с, статистика начислена, DOM очищен.
- 3 призрака = разрыв петли; кнопка без призраков = бесконечная петля с гэгами (не блокирует,
  авто-таймер подстраховывает).

### Известные ограничения
- Призрак ловится только тапом (по дизайну — «мелькает»); тап по большой кнопке во время
  очистки памяти игнорируется (короткая анимация ~1 с).
- Счётчик «+47» комедийно не сходится с +200 (так задумано; на 3-м нажатии система шутит
  «АРИФМЕТИКА УСТАЛА»).

## Эп6 — G.scenes.boss (src/js/16-ep-boss.js)

### Арена и босс
- Классная сцена **остаётся видимой сверху**: учительница/Толя/Вика/Гоша меняют настроения и
  комментируют через `c.say`/stage. В зоне сцены — арена: canvas-фон (буря армянских букв,
  молнии, мел), в центре **доска с лицом** — «ПЕДАГОГИЧЕСКИЙ ХАОС» (глаза следят за указателем,
  рот/брови меняются по фазам, трещины по числу спасённых артиклей, при смерти — X-глаза и
  разлом; HUD «СПАСЕНО: n · прогресс фазы»).
- Реплики босса — строка на арене (по мотивам `G.text.article.lines`/`G.text.system`).
  Статистика: **bossHits, articlesSaved, errors, protocols, articlesLost**.

### Фаза 1 «Артиклевая буря» — 4 крепления
- Падают слова (14 слов на ը + 4 на ն: տուն/գիրք/հաց/ջուր/քաղաք/դաս/սեղան/փողոց/դպրոց/խանութ/
  ծով/սար/մարդ/գետ → **ը**; կատու/տղա/երեխա/ձի → **ն**), под словом — русский перевод,
  последняя буква подсвечена.
- Внизу два живых артикля **Ը** и **Ն** (`G.art.drawArticle`, canvas). Крепление: **тап артикля →
  тап слова** или **drag артикля на слово** (pointer capture). Верно: слово становится
  определённым (տունը/կատուն), улетает с burst, +1 saved/bossHits. Неверно: шоковая волна
  «ГДЕ АРТИКЛЬ?!», shake/flash, крик учительницы, протокол, errors+1, прогресс не теряется.
  Пропущенное слово — лист в стопку ДЗ, articlesLost+1 (каждое 3-е — протокол).
- Подсказка «хвост слова» на токенах + строка-инструкция (без лекции по грамматике).

### Фаза 2 «Мы это уже проходили» — 3 крепления
- Токены **меняются местами** каждые ~3.6 с, подписи-подсказки путаются; слова падают быстрее,
  часть переводов комедийно заменена на «мы это уже проходили».
- В центре появляется **огромная фальшивая кнопка «МЫ ЭТО УЖЕ ПРОХОДИЛИ!»** (телепортируется,
  меняет надпись). Нажатие **откатывает прогресс фазы** (счётчик 0/3, глитч, протокол, крик
  Вики «Я это уже проходила. Дважды.»). После 2 откатов кнопка уезжает на совещание
  («КНОПКА «МЫ ЭТО УЖЕ ПРОХОДИЛИ» УШЛА НА СОВЕЩАНИЕ.»), дальше не мешает.
- После 1-го крепления — **фальшивое системное окно** `c.fx.fakeWindow` «ОБНОВЛЕНИЕ АРТИКЛЯ»,
  пароль-кнопки **ՏՈՒՆ / ՏՈՒՆԸ / ՏԱՆԸ**; верный — **ՏՈՒՆԸ**. Верно: «ДОСТУП РАЗРЕШЁН. АРТИКЛИ
  ВЫДАНЫ. НЕ ВСЕ.», неверно: глитч/ошибка и окно открывается ещё раз (не более 2 попыток, потом
  «ОКНО УСТАЛО» — тупика нет). Во время окна арена замирает.

### Фаза 3 «Последний артикль» — погоня, 5 тапов
- Артикль **в короне** (canvas `G.art.drawArticle(..., {crown:true})`) летает по арене,
  уворачивается от указателя, ускоряется после каждого попадания, иногда телепортируется.
- Каждый тап срывает **маскировку**: ВИКА → ДОМАШНЕЕ ЗАДАНИЕ → ПРОТОКОЛ № 47 →
  ПЕДАГОГИЧЕСКИЙ ХАОС → АРТИКЛЬ; экран всё сильнее **заливает ДЗ** — листы с реальными пунктами
  `G.text.homework` (47 пунктов, последний — «Найти артикль»), к 5-й поимке — почти весь экран.
- Победа: burst, корона слетает, доска трескается, **слоу-мо** (замедление бури/листов),
  затем **`c.fx.silence(1500)`** — чёрная драматическая тишина, resolve. Финал/диплом не
  дублирую — его делает сцена `finale`.
- Без game over; при простое 26 с артикль «устаёт убегать» и сцена гарантированно доходит до
  победы (фейлсейф), при простое в P1/P2 — «ХАОС УСТАЛ ЖДАТЬ. АРТИКЛИ ПРИКРЕПЛЕНЫ ИЗ ЖАЛОСТИ.»
- **Достижение**: `too_perfect` — если в боссе ни одной ошибки (выдаётся после P2, чтобы не
  перебивать драматическую тишину). Гэги: boss_phase1/2/3, boss_rollback, boss_password_ok/fail,
  boss_hit_1..9, boss_chase_1..5, boss_crown, boss_papers, boss_phase2_done, boss_phase3_done.
- **c.auto**: завершение ~1.2 с, bossHits=8, articlesSaved=8, protocols=1, gag boss_auto.
- Длительность: ~40–50 с у быстрого игрока, ~90–110 с с чтением/попытками.

### Проверено
- `node --check src/js/16-ep-boss.js` OK; `node tools/build.mjs` OK.
- Playwright 390×844 (hasTouch, **реальные** touch-тапы): полный проход P1→P2 (пароль реальным
  тапом по кнопке ՏՈՒՆԸ) → P3 (5 реальных тапов) → победа/тишина/scene-root удалён.
  stats: bossHits=13, articlesSaved=8, errors=0, gags=21, console/pageerror — нет.
- Откат фальшивой кнопкой: protocols+1 за каждое нажатие, прогресс фазы 0/3, после 2 — кнопка
  `disabled`, тост «ОТКАТ ФАЗЫ · ПРОТОКОЛ № 48/49». Пароль проверен и реальным тапом, и
  pointerdown: `boss_password_ok`, окно закрывается, errors не растёт.
- Drag-крепление на 1280×800 (мышь): pointerdown на токене → move → up над словом →
  bossHits+1, слово стало տուն+ը/…; без drag — тап-тап.
- `?scene=boss&only=1&auto=1` — 1.2 с, статистика начислена, DOM очищен.
- 1280×800: слова/токены/окно/маскировка/ДЗ читаемы, HUD не перекрывает слова.

### Известные ограничения
- Артикль ловит тап по самому элементу (движется плавно; для QA удобнее
  `dispatchEvent('pointerdown')` или touch-tap по boundingBox).
- Пароль — кнопки вместо поля ввода: контракт `c.fx.fakeWindow` не имеет input (так и в
  DESIGN: «фальшивое системное окно с паролем տունը»).
- Ловушка «Мы это уже проходили» не наказывает навсегда: 2 отката, затем уходит.
