## 3. Диплом — API и рекомендации вёрстки

G.text.diploma:
- ministry = «Министерство потерянных артиклей»
- title = «СВИДЕТЕЛЬСТВО О ПЕРЕЖИТОМ УРОКЕ»
- signedBy = «Полицейский (ныне министр)»
- stamp = «ՀՈԴԸ ՏԵՂՈՒՄ Է» (по-армянски «артикль на месте», реальный термин հոդ)
- rankFor(stats) → строка звания (9 вариантов, приоритетный порядок, fallback «Свидетель урока»). Устойчиво к null/{}.
- statsLines(stats) → массив 9–10 строк с реальными счётчиками и шутками (нули тоже смешные).
- shareText(stats) → многострочный текст для шаринга.
- footnote — мелкий шрифт.

Пример:
    var d = G.text.diploma;
    var rank = d.rankFor(G.state.stats);
    var lines = d.statsLines(G.state.stats);
    var share = d.shareText(G.state.stats);

Звания и правила — script.md §8.2; строки — §8.3; шаринг — §8.4. Все ключи — из TECH §8; счётчик гэгов считается по stats['gag:*'] (Lead подтвердил, что c.gag пишет такие ключи).

## 5. Пулы реплик

G.text.pools.ep1..ep6 {ok[], bad[], esc[]} — по 2–5 готовых реплик. Рекомендации девам:
- ok — на верное действие (не чаще 1 раза в 3–4 секунды, чтобы не заспамить);
- bad — на ошибку, всегда вместе с эффектом (взрыв, тряска, протокол), не вместо него;
- esc — при смене стадии раунда;
- выбирать случайно через G.state/seed (детерминизм при ?seed=1), не Math.random напрямую, чтобы QA воспроизводил.

## 6. Известные ограничения и риски

1. i1 — 36 шагов, по моим ms ≈ 40–45 сек (тапом ≈ 18). Если покажется долгим: резать безопасно блок Гоши (шаги с «Я ничего не видел») и пару реплик полицейского ПОСЛЕ первого протокола, но не первые 5 шагов — первый гэг должен остаться в первые ~5 секунд.
2. Намеренная ошибка Вики в i4: «Я всегда пишу պ. Это базовое.» — это ОШИБКА ПЕРСОНАЖА (правильно բ). Учительница тут же выписывает протокол. Не «исправлять» при QA; описание — script.md §11.
3. Последний пункт homework — «Найти артикль.» (с точкой). Если в финале нужна строка без точки — скажите, поменяю.
4. Список ДЗ в финале полностью рендерит движок катсцен по {homework:true} из G.text.homework; катсцены i* его не используют.
5. students — массив; studentById — объект на те же объекты. Структуру не менять.
6. article.name используется в бабблах (подтверждено Lead) — «Артикль Ը».
7. Достижение mute_eyes требует проверки G.audio.muted на финише Эп3 — это зона dev-chase, договоритесь с ними (я написал в script.md §7).
8. Мои правки в 05-content.js в будущем — только аддитивные (новые id достижений/реплики), структуру G.text/G.cutscenes/iN не меняю; при любом изменении предупреждаю Lead.
