# Handoff: dev-chase — Эп2 «Я ЖЕ ЗНАЛ ЭТО СЛОВО!» и Эп3 «ПОВТОРИТЕ, ПОЖАЛУЙСТА»

Статус: **готово**, обе сцены работают в dev.html и в собранном gde-artikl.html.
Файлы зоны dev-chase (только они менялись):
- `src/js/12-ep-memory.js` — `G.scenes.memory` (Эп2)
- `src/js/13-ep-hear.js` — `G.scenes.hear` (Эп3)

## Эп2 — «Я ЖЕ ЗНАЛ ЭТО СЛОВО!» (`G.scenes.memory`, ~45–70 сек)

Полноэкранный слой `c.layer` (`.ep2-layer`), классная сцена скрыта (`c.stage.hide()`): игрок внутри мозга.

Биты:
1. Голос извне: «Как будет «хлеб»?» → «ПАМЯТЬ. ТУТ ПАХНЕТ ХЛЕБОМ. ЭТО ЛОВУШКА.»
2. Показ цели 1.4 сек (карточка-задание հաց / хлеб), поле в этот момент притушено и размыто.
3. Райнд «հաց»: 9 карточек на 3 полках (цель + 8 дистракторов). Карточки дрейфуют, качаются,
   дистракторы переворачиваются рубашкой; цель каждые 3.8–4.4 сек перепрыгивает на чужой слот
   (обменивается местами, проезжает по полкам).
4. Тап по цели → карточка вспыхивает, разлетаются армянские глифы, `memoryFinds+1`, слот
   «НАЙДЕНО: հաց» заполняется, реплика из `c.text.pools.ep2.ok`.
5. Тап по дистрактору → карточка возмущается репликой из `pools.ep2.bad` (бессмысленная подсказка),
   `errors+1`, туман густеет (счётчик «ТУМАН»), все карточки перетасовываются, иногда цель телепортируется.
   На **первом** промахе — `c.achievement('anki47')` («Anki звонил 47 раз»). Прогресс не откатывается.
6. Между райндами: глитч, «ПАМЯТЬ ПЕРЕСТРАИВАЕТ ПОЛКИ. БЕЗ ПРЕДУПРЕЖДЕНИЯ.», esc-реплика, туман+.
7. Райнд «ջուր»: больше тумана, цель прыгает чаще (2.6–2.9 c), флипы чаще, в колоде
   այո/վաղը/շատ/լավ и т.п.
8. Финал: третий вопрос учительницы извне («А как будет «дом»?») → system-реплика из
   `G.text.system` («ПАМЯТЬ ОЧИЩЕНА. ОСВОБОЖДЕНО: 0 БАЙТ.») → esc-реплика из `pools.ep2.esc`
   («Третий вопрос учительницы. Мозг прилёг.») → «мозг выключается», возврат.

Статистика/гэги: `memoryFinds` (2), `errors` (промахи), `c.gag`: `ep2_target_hop`, `ep2_fog`,
`ep2_shuffle`, `ep2_reindex`, `ep2_brain_freeze`, `ep2_third_question`; достижение `anki47`.

## Эп3 — «ПОВТОРИТЕ, ПОЖАЛУЙСТА» (`G.scenes.hear`, ~40–75 сек)

Классная сцена видна сверху (арт Visual), игровая зона снизу: субтитры, индикатор понимания,
визуализатор звука, зона слышимости, большая кнопка и убегающая кнопка «Я ПОНЯЛ».

Биты:
1. Учительница: «Повторите, пожалуйста.». Фраза **Ես այսօր տանը հաց եմ ուտում** + подстрочник
   «Я сегодня дома ем хлеб». Индикатор понимания: +6%.
2. Кнопка **«ПОВТОРИТЕ, ПОЖАЛУЙСТА»** — каждое нажатие: субтитры мутируют (дубли слов → буквы →
   перемешанные слова → глитч-шум), подстрочник рассыпается («Я сегод...» → «...» → «ПОВТОРИТЕ ГЛАЗАМИ»),
   изо рта учительницы летят армянские слова, громкость/волна растут, кнопка растёт, появляются
   кнопки-копии, индикатор понимания: **−12% → −58% → −142%** (красная полоса, тряска числа),
   учительница ускоряется (bubble-time сокращается, настроение calm → suspicious → cosmic → scream),
   тосты из `G.text.system` («ГРОМКОСТЬ ПОВЫШЕНА ДО «ПЕДАГОГИЧЕСКОЙ»» и т.п.).
3. После 1-го нажатия появляется малюсенькая кнопка **«Я ПОНЯЛ»** (86x34): убегает от указателя
   (pointermove, радиус 74 px), телепортируется сама каждые ~2.2–3.2 c, пищит «пи!».
4. Нажатие «Повторите» **оглушает** её на ~1.05 c (зелёная подсветка) и ставит рядом с большой кнопкой —
   окно, чтобы поймать. Через 3 тапа (с блокировкой между ними) — финал.
   После каждой поимки кнопка **блокируется** (🔒) — система: «КНОПКА «Я ПОНЯЛ» НЕДОСТУПНА. ПРИЧИНА: САМООЦЕНКА.»
   (реплика из `G.text.system`); очередное «Повторите» разблокирует. Так игрок проходит
   цикл повтор→хаос→поимка, и цифры −142% достигаются естественно.
5. Гэги: кнопка-копия; на 2-й поимке — системное окно «СИСТЕМА ЗВУКА»: «ЗВУК НЕ НАЙДЕН. ПОВТОРИТЕ ГЛАЗАМИ.»
   с убегающей кнопкой «ПОВТОРИТЬ ГЛАЗАМИ» (c.fx.fakeWindow, `runaway`).
6. Финал: третья поимка → всё гаснет (silence), учительница вкрадчиво: **«Что ты понял?»** →
   драматическая пауза → сцена завершается. «· · ·» в тикере, индикатор замирает на −142%.

Статистика/гэги: `repeats` (каждое нажатие, минимум 3 за прохождение), `c.gag`: `ep3_repeat`,
`ep3_catch`, `ep3_catch_2`, `ep3_catch_3`, `ep3_sound_not_found`, `ep3_finale`.

## Использованные API (по контракту TECH.md §3–§5)
- `c.layer` + `c.fullscreen(true)` (Эп2 — весь экран, Эп3 — слой для слов/вспышек),
  `c.root`/`c.add` (Эп3 UI), `c.el`, `c.tap`, `c.wait`, `c.raf`, `c.cleanup`.
- `c.stage.hide/show/mood/say`, `c.cSay`-эквивалент `c.say` (Эп3), `c.fx.shake/glitch/silence/fakeWindow`
  (в Эп2 `flash/burst/spotlight` недоступны: они рисуются под полноэкранным слоем, поэтому в эпилоге
  сделаны собственные частицы/вспышки внутри слоя).
- `c.bump`, `c.gag`, `c.achievement`, `c.text.pools.ep2/ep3`, `c.text.system`, `c.text.teacherName`.
- Звук опционален: все вызовы через `if (c.audio && c.audio.sfx)`, визуально всё читается без звука.

## c.auto (для QA)
- `memory`: ждёт 1.2 c, `memoryFinds += 2`, завершает сцену.
- `hear`: ждёт 1.2 c, `repeats += 2`, завершает сцену.
Обе сцены завершаются сами (проверено: слой/разметка исчезают, ошибок нет).

## Анти-блок (как выйти, если что-то пошло не так)
В сценах нет game over и нет тупиков:
- **Эп2**: если слово не найдено за 40 c, мозг «сдаётся» и отдаёт слово сам (райнд засчитывается).
- **Эп3**: watchdog каждые 2.6 c:
  - если 14 c нет нажатий «Повторите» — учительница повторяет сама (кнопка начинает цикл);
  - если 9 c пойманная кнопка «Я ПОНЯЛ» не ловится — её снова оглушают;
  - если 14 c кнопка заблокирована — автоматический повтор её разблокирует;
  - полностью пассивный игрок: сцена сама нажимает «Я ПОНЯЛ» (30 c, затем каждые 18 c) и доходит до финала.
    Проверено на живом прогоне: без единого тапа сцена завершилась сама на **76 c** со статистикой
    repeats=3, memoryFinds=0, gags=6; система пишет «КНОПКА «Я ПОНЯЛ» НАЖАТА БЕЗ ВАС. ТАК ТОЖЕ БЫВАЕТ.».
- **Глобально**: `?debug=1` → кнопка ⏭ в HUD (`__GAME__.skipCurrent()`) прерывает сцену;
  после пропуска/ошибки надёжнее перезагрузить страницу (см. известное ограничение ниже).

## Визуальные/контентные замечания Lead'у
1. **Небольшие собственные строки** (UI/режиссура, не из `G.text`) — можно заменить/переписать Comedy:
   - Эп2: «ВНУТРИ ПАМЯТИ», «ПОЛОК: МНОГО · СЛОВА ПРЯЧУТСЯ», «ЗАДАНИЕ ИЗВНЕ: НАЙДИ СЛОВО»,
     «СМОТРИ · ЗАПОМИНАЙ · ОНО СПРЯЧЕТСЯ», «НАЙДЕНО:», «ТУМАН», «ПАМЯТЬ. ТУТ ПАХНЕТ ХЛЕБОМ. ЭТО ЛОВУШКА.»,
     «ПАМЯТЬ ПЕРЕСТРАИВАЕТ ПОЛКИ. БЕЗ ПРЕДУПРЕЖДЕНИЯ.», «МОЗГ УСТАЛ И ОТДАЛ СЛОВО ДОБРОВОЛЬНО.»,
     «А как будет «дом»?» (третий вопрос — по DESIGN).
   - Эп3: «ПОВТОРЕНИЕ», «ПОЙМАНО 0/3 · ПОВТОРОВ 0», «ИНДИКАТОР ПОНИМАНИЯ», «ЗОНА СЛЫШИМОСТИ»,
     «НЕ ВЫХОДИТЕ», «ПОЯВИЛАСЬ КНОПКА «Я ПОНЯЛ». ОНА НЕ ХОЧЕТ, ЧТОБЫ ЕЁ НАЖАЛИ.»,
     «Кнопка заблокирована. Повторите — откроется.», «Кнопка устала ждать. Повторите — или ловите.»
     (+ системные тосты и «Что ты понял?» — из `G.text.system`/DESIGN).
   Эп3: мутации субтитров специально ломают армянскую фразу (шутка), исходная фраза всегда
   показана в начале и в подстрочнике **правильная**.
2. Армянский материал — только из TABLE DESIGN §8: հաց/ջուր + տուն, գիրք, կատու, տղա, դաս, սեղան,
   ծով, սար, այո, վաղը, մարդ, դպրոց, քաղաք, լավ, շատ; фраза Ես այսօր տանը հաց եմ ուտում.
3. Эп3 использует `c.say` для фразы учительницы; на **320x568** длинный баббл частично уходит под HUD
   (sound ⏭) — это общий лейаут `base.css`/HUD (не моя зона); на 390x844 чисто.
4. Эп2 намеренно скрывает классную сцену (полноэкранный «внутри мозга»); `c.say` в нём не используется —
   диалог идёт через собственные оверлеи слоя.
5. Известное debug-ограничение `00-core`: `__GAME__.start('<scene>')` после одиночной сцены/skip
   на той же странице не перезапускает сцену — QA перезагружает страницу (по решению Lead не чиним).

## Проверки (команды)
```
node tools/build.mjs
node tools/shot.mjs "dev.html?scene=memory&only=1&debug=1" screenshots/ep2.png 1280 800 3600
node tools/shot.mjs "dev.html?scene=hear&only=1&debug=1" screenshots/ep3.png 390 844 1600 --mobile
```
Интерактив проверялся временными playwright-core скриптами (тапы через `dispatchEvent(new PointerEvent('pointerdown'))`
— обычный `locator.tap()` не работает на непрерывно анимированных карточках/кнопке); после проверки скрипты удалены,
чтобы не трогать чужие файлы.
